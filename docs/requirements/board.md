# Board Requirements

## 목적

사용자가 게시글을 작성, 조회, 수정, 삭제할 수 있는 게시판 기능을 정의한다.

## 기능 요구사항

- 사용자는 게시글 목록을 조회할 수 있어야 한다.
- 사용자는 게시글 상세 정보를 조회할 수 있어야 한다.
- 인증된 사용자는 게시글을 작성할 수 있어야 한다.
- 작성자는 자신의 게시글을 삭제할 수 있어야 한다.
- 게시글 목록은 최신순 등 정해진 정렬 기준으로 제공되어야 한다.

## 비기능 요구사항

- 게시글 작성/삭제는 인증된 사용자 권한 기준으로 처리되어야 한다.
- 게시글 목록 조회는 페이지네이션 또는 제한된 조회 범위를 통해 과도한 응답 크기를 방지해야 한다.
- 게시글 내용은 클라이언트 표시 과정에서 스크립트 삽입 등 보안 문제가 발생하지 않도록 처리되어야 한다.
- 삭제된 게시글은 일반 조회 결과에 노출되지 않아야 한다.

## 예외/제약사항

- 존재하지 않는 게시글 조회/삭제 요청은 실패해야 한다.
- 작성자가 아닌 사용자는 게시글을 삭제할 수 없다.
- 게시글 제목과 내용은 빈 값일 수 없다.

## 관련 API

- `GET /api/v1/board/list`: 게시글 목록 조회
- `GET /api/v1/board/{boardId}`: 게시글 상세 조회
- `POST /api/v1/board`: 게시글 작성
- `DELETE /api/v1/board/{boardId}`: 게시글 삭제

## 검증 시나리오

- 사용자는 게시글 목록과 상세를 조회할 수 있다.
- 인증된 사용자는 제목과 내용으로 게시글을 작성할 수 있다.
- 작성자가 자신의 게시글을 삭제할 수 있다.
- 작성자가 아닌 사용자의 삭제 요청은 실패한다.
