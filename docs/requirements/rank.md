# Rank Requirements

## 목적

사용자와 학부의 학습 시간을 기준으로 개인, 학부, 시즌 랭킹을 제공한다.

## 기능 요구사항

- 사용자는 일간 개인 랭킹을 조회할 수 있어야 한다.
- 사용자는 주간 개인 랭킹을 조회할 수 있어야 한다.
- 사용자는 월간 개인 랭킹을 조회할 수 있어야 한다.
- 사용자는 학부 단위 랭킹을 조회할 수 있어야 한다.
- 사용자는 시즌 랭킹을 조회할 수 있어야 한다.
- 랭킹에는 조회 기간에 해당하는 학습 시간이 반영되어야 한다.
- 실시간 랭킹이 필요한 경우 진행 중 학습 세션의 현재까지 시간을 포함할 수 있어야 한다.
- 사용자는 랭킹 목록에서 자신의 순위를 확인할 수 있어야 한다.

## 비기능 요구사항

- 랭킹 산정 기준은 개인/학부/시즌 랭킹에서 일관되게 적용되어야 한다.
- 랭킹 조회는 대량 사용자 데이터에서도 응답 지연이 과도하지 않아야 한다.
- 스냅샷 기반 랭킹은 생성 시점과 기준 기간을 추적할 수 있어야 한다.
- 동점자 처리와 제외 대상 처리 기준은 재계산 시에도 동일해야 한다.
- 랭킹 조회 결과는 다른 사용자의 민감 정보를 노출하지 않아야 한다.

## 예외/제약사항

- 탈퇴한 사용자 또는 랭킹 노출 대상이 아닌 사용자는 랭킹에서 제외되어야 한다.
- 학부 정보가 없는 사용자는 학부 랭킹 산정에서 제외될 수 있다.
- 동점자 처리 기준은 일관되게 적용되어야 한다.

## 관련 API

- `GET /api/v1/rank/personal/daily`: 일간 개인 랭킹
- `GET /api/v1/rank/personal/weekly`: 주간 개인 랭킹
- `GET /api/v1/rank/personal/monthly`: 월간 개인 랭킹
- `GET /api/v1/rank/department/daily`: 일간 학부 랭킹
- `GET /api/v1/rank/department/weekly`: 주간 학부 랭킹
- `GET /api/v1/rank/department/monthly`: 월간 학부 랭킹
- `GET /api/v1/rank/season/current`: 현재 시즌 개인 랭킹
- `GET /api/v1/rank/season/current/department`: 현재 시즌 학부 랭킹
- `GET /api/v1/rank/season/{seasonId}`: 특정 시즌 개인 랭킹
- `GET /api/v1/rank/season/{seasonId}/department`: 특정 시즌 학부 랭킹

## 검증 시나리오

- 학습 시간이 많은 사용자 순서대로 개인 랭킹이 반환된다.
- 학부별 누적 학습 시간이 많은 순서대로 학부 랭킹이 반환된다.
- 진행 중 세션을 포함하는 랭킹은 현재 시점까지의 시간을 반영한다.
- 사용자는 자신의 랭킹 정보를 확인할 수 있다.
