# Statistics Requirements

## 목적

사용자의 학습 기록을 기반으로 기간별 통계와 잔디형 학습 현황을 제공한다.

## 기능 요구사항

- 사용자는 일간 학습 통계를 조회할 수 있어야 한다.
- 사용자는 주간 학습 통계를 조회할 수 있어야 한다.
- 사용자는 월간 학습 통계를 조회할 수 있어야 한다.
- 사용자는 날짜별 학습 여부와 시간을 잔디형 데이터로 조회할 수 있어야 한다.
- 통계는 사용자의 완료된 학습 세션을 기준으로 산출되어야 한다.
- 기간 경계를 걸친 학습 세션은 해당 기간과 겹치는 시간만 반영되어야 한다.

## 비기능 요구사항

- 통계 계산은 기간 경계와 시간대 기준을 일관되게 적용해야 한다.
- 사용자의 통계 조회는 다른 사용자의 학습 기록을 노출하지 않아야 한다.
- 빈 기간과 데이터가 있는 기간의 응답 구조는 클라이언트가 안정적으로 처리할 수 있도록 일관되어야 한다.
- 월간/잔디형 통계처럼 범위가 넓은 조회는 과도한 DB 부하를 유발하지 않아야 한다.

## 예외/제약사항

- 사용자는 자신의 통계만 조회할 수 있어야 한다.
- 학습 기록이 없는 기간은 0 또는 빈 데이터로 일관되게 표현되어야 한다.
- 진행 중 세션을 통계에 포함할지 여부는 API별 정책에 따라 명확해야 한다.

## 관련 API

- `GET /api/v1/statistics/day`: 일간 통계 조회
- `GET /api/v1/statistics/week`: 주간 통계 조회
- `GET /api/v1/statistics/month`: 월간 통계 조회
- `GET /api/v1/statistics/grass`: 잔디형 통계 조회

## 검증 시나리오

- 학습 기록이 있는 날짜의 총 학습 시간이 정확히 반환된다.
- 학습 기록이 없는 날짜는 0 또는 빈 데이터로 반환된다.
- 기간 경계를 넘는 세션은 조회 기간에 해당하는 시간만 반영된다.
- 다른 사용자의 학습 기록은 통계에 포함되지 않는다.
