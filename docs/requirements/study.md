# Study Requirements

## 목적

사용자의 학습 세션 시작, 종료, 시간 계산, 자동 종료 조건을 정의한다.

## 기능 요구사항

- 사용자는 캠퍼스 Wi-Fi 검증에 성공한 경우 학습 세션을 시작할 수 있어야 한다.
- 사용자는 현재 진행 중인 학습 세션을 종료할 수 있어야 한다.
- 학습 세션의 시작/종료 시간은 서버 시간을 기준으로 기록되어야 한다.
- 사용자는 오늘의 학습 세션과 누적 학습 시간을 조회할 수 있어야 한다.
- 사용자는 동시에 하나의 진행 중 학습 세션만 가질 수 있어야 한다.
- 진행 중인 학습 세션은 최대 집중 시간 정책에 따라 자동 종료될 수 있어야 한다.
- 하트비트 기반 세션 관리가 적용되는 경우, 하트비트 중단 시 세션이 자동 종료될 수 있어야 한다.

## 비기능 요구사항

- 학습 시간 계산은 서버 시간을 기준으로 일관되게 처리되어야 한다.
- 학습 세션 시작/종료는 중복 요청이나 동시 요청에도 세션 상태가 깨지지 않아야 한다.
- 자동 종료 스케줄러 실패는 로그로 추적 가능해야 하며 다음 실행에서 복구 가능해야 한다.
- Wi-Fi 검증 실패나 외부 인프라 장애는 명확한 실패 응답으로 전달되어야 한다.
- 장시간 세션 조회와 랭킹 반영에 필요한 시간 계산은 성능 저하가 크지 않도록 설계되어야 한다.

## 예외/제약사항

- 캠퍼스 Wi-Fi 검증에 실패하면 학습 세션을 시작할 수 없다.
- 이미 진행 중인 학습 세션이 있으면 새 학습 세션을 시작할 수 없다.
- 존재하지 않거나 본인 소유가 아닌 학습 세션은 종료할 수 없다.
- 종료 시간이 시작 시간보다 앞서는 세션은 유효하지 않다.

## 관련 API

- `POST /api/v1/study/start`: 학습 세션 시작
- `POST /api/v1/study/end`: 학습 세션 종료
- `GET /api/v1/study`: 오늘의 학습 세션 조회

## 검증 시나리오

- 캠퍼스 Wi-Fi 검증에 성공하면 학습 세션이 시작되고 세션 ID가 반환된다.
- 진행 중인 학습 세션이 있는 사용자가 다시 시작을 요청하면 실패한다.
- 사용자가 세션 종료를 요청하면 서버 시간이 종료 시간으로 기록되고 총 학습 시간이 계산된다.
- 최대 집중 시간을 초과한 진행 중 세션은 자동 종료된다.
- 자정을 넘긴 세션도 올바른 학습 시간으로 계산된다.
